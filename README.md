## FURP Deliverables

- Keep attendance above 50% of all FURP activities.
- Update `docs/00_weekly.md` every week.
- Record key meeting takeaways in `docs/meeting_notes/`.
- Develop project code and experiments under `src/`.
- Add the final research poster or presentation PDF as `FURP_Showcase.pdf` in the repository root before the Showcase.
- Present the poster at the Showcase, in person if possible, or arrange a stand-in.
